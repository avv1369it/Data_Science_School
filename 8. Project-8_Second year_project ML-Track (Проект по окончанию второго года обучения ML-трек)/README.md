## Описание проекта `<a id="one"></a>`

Учебный проект направленный на отработку и закрепление полученных знаний в рамках обучения по специализации ML-трек профессии Data Science в течение 2 года обучения. В течение данного периода были изучены следующие блоки и темы:

* Data Engineering: CAP теорема; SQL и NoSQL базы данных; Репликация и шардирование; Парсинк данных; Экосистема Hadoop; Парадигма MapReduce; SparkML;
* Углубленное изучение Python: Предобработка текстов; Обработка временных рядов; Scipy; Статистические тесты;
* Углубленное изучение Data Science: Рекомендательные системы; Детектирование аномалий; Байесовские методы; Ядерные функции; Uplift-моделирование;
* Оценка экономической эффективности и MVP: Принципы быстрого создания MVP; Оценка качества моделей; A/B тестирование;
* Data Science в продакшен: Деплой и интеграция; Контейнеризация и работа с облаками; Мониторинг и управление качеством моделей;
* Реальная жизнь ML инженера на примсерах работы: В IT компаниях, в банках, в ритейле.

## Какой кейс решаем `<a id="two"></a>`

**Компания ритейл (заказчик)** - поставил задачу повысить прибыль от дополнительных продаж в интернет-магазине, не менее чем на 20%, за счет внедрения рекомендательной системы, которая должна выводить 3 товара на главной странице сайта (посетителя).

Заказчиком принято решение производить оценку работы моделей с помощью метрики - ***Precision@3*** - точность по первым 3 рекомендациям.

⬆️[к оглавлению](.README.md#Оглавление)

## Задачи проекта `<a id="three"></a>`

**Бизнес-задача:** повышение прибыли от дополнительных продаж в интернет магазине не менее чем на 20% от внедрения рекомендательной системы на главной странице сайта.

**Техническая задача (как для специалиста в Data Science):** разработать и внедрить рекомендательную систему, не менее 3-х товаров, на главной странице интернет-магазина таким образом, чтобы повысить продажи дополнительных товаров не менее чем на 20%.

## Краткая информация о данных `<a id="six"></a>`

Скачать данные можно на Kaggle [Retailrocket recommender system dataset](https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset).

>Набор данных состоит из трех файлов: файла с данными о поведении (events.csv), файла со свойствами элемента (item_properties.csv: представлен 2 файлами) и файл, описывающий дерево категорий (category_tree.csv). Данные были собраны с реального веб-сайта электронной коммерции. Это необработанные данные, то есть без каких-либо преобразований содержимого, однако все значения хэшируются из-за проблем с конфиденциальностью. Цель публикации - мотивировать исследования в области рекомендательных систем с неявной обратной связью.

## Результат `<a id="seven"></a>`

**На сайте представлены следующие материалы:**

* FinalProject(GitHub)_final.ipynb - Jupyter Notebook с этапами реализации проекта;
* Папка libraries - в папке представлены 4 Jupiter Notebooks c рассматриваемыми библиотеками в рамках расчета и оценки алгоритмов библиотек (представлены 4, как образцы);
* Папка results - в папке представлены csv файлы с данными о работе алгоритмов разных библиотек;
* Папка docker - в папке представлены файлы для создания docker контейнера и web - сервиса;
* Презентация для представления Заказчику.

**Проверка работы модели (API):**
1. Зайдите на Docker Hub по ссылке: https://hub.docker.com/repository/docker/avv1369/recommender_sistem/general
2. Загрузите образ на свой компьютер (объем 3.64+ GB, отдельно модель 2.2GB): docker pull avv1369/recommender_sistem:latest
3. В терминале или командной строке IDE запустите контейнер: docker run -d -p 8080:5000 avv1369/recommender_sistem:latest
4. Откройте браузер и введите адрес: 127.0.0.1:8080
5. В появившемся окне в поле «Введите UserID» - введите ID клиента (пример 899080), нажмите поле - получить рекомендации
6. Появится окно с рекомендациями для пользователя с фотографиями (фотографии выбираются случайным образом из 10 загруженных и для одного пользователя могут быть разными). Если ID клиента не представлен в модели, будет выведена надпись: «Клиент с ID отсутствует или для него нет рекомендаций».

## Выводы `<a id="eight"></a>`

**Что сделано:**

1. Рассмотрено несколько основных библиотек для построения рекомендательных систем: Implicit; Suprise; LightFM. Прикоснулся к библиотеке Recommenders;
2. Произвел оценку работы разных алгоритмов: ближайшие соседи; матричной факторизации, нейронные сети;
3. Рассмотрены методы работы с "неявными" оценками и влияние их на конечный результат метрики оценки работы моделей;
4. Рассмотрены методы деления данных данных и влияние их на конечный результат метрики оценки работы моделей.

**Что не получилось:**

1. Разработка рекомендательных систем требует довольно серьезных машинных ресурсов. К сожалению домашний компьютер не позволил качественно поработать с нейронными сетями для разработки рекомендательных систем и гибридными моделями.

**Резюме:**

1. В соответствии с полученными результатами для построения финальной модели выбираем модель на базе алгоритма LightFM (collaborative filtering) библиотеки LightFM.
